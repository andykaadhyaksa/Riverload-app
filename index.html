Input Data Sungai

Export Laporan
Generate laporan Excel berwarna dan Word terstruktur. Simpan proyek ke riwayat browser atau ekspor ke file .riverload untuk dibagikan ke rekan kerja.

Usulan Baku Mutu Maksimum Air Limbah
FORMULA
Cmaks = [ BM × (Qs + ΣQi) − Qs × Chulu ] / ΣQi
Nilai ini adalah konsentrasi maksimum air limbah yang masih dapat dibuang sehingga CR hilir sungai tepat sama dengan Baku Mutu kelas sungai yang dipilih.
Diambil nilai terkecil antara musim kemarau dan hujan (kondisi kritis). Jika Cmaks < 0 → konsentrasi hulu sudah melampaui BM, tidak ada ruang pencampuran.

FISHBONE
Diagram skematik posisi Outfall sepanjang sungai — debit musim hujan/kemarau di hulu
ℹ  Diagram ini hanya gambaran skematik (bukan skala jarak sebenarnya). Posisi tiap Outfall diatur proporsional sepanjang garis sungai berdasarkan jumlah Nama Sumber / Titik Penaatan yang sudah diisi di menu Usulan Baku Mutu. Debit hulu (Q_Hujan / Q_Kemarau) diambil dari menu Beban Pencemar.
🔢 Susun Urutan Outfall
Khusus kalau sumber air limbah lebih dari satu — atur urutan dari hulu ke hilir pakai tombol ▲▼. Posisi di diagram otomatis menyesuaikan.
Belum ada "Nama Sumber / Titik Penaatan" di menu Usulan Baku Mutu — diagram di atas hanya menunjukkan garis HULU → HILIR tanpa titik Outfall.
